AI Resume Screening System

An AI-powered resume screening project built using Python and Groq API to analyze resumes and extract relevant candidate information in a structured JSON format.

Functionality

Analyzes resume content using an LLM.

Extracts important candidate details and skills.

Converts unstructured resume information into structured JSON.

Uses Pydantic for data validation.

Generates structured AI responses.

Technologies Used

Python

Groq API (LLM)

Pydantic

JSON

python-dotenv
